Michael Vladimirsky

A keyboard and a gamepad in one device. Hall-effect sensors in the keys measure how far each key is pressed instead of just on or off, and a Nintendo Switch-style rotary D-pad handles directional input. This project is still in progress.

The brain is an RP2040 microcontroller. It has two cores, so one core polls and debounces the keyboard matrix while the other reads the controller inputs, and the device connects over USB-C. I designed the PCB in KiCad. The main engineering challenge is crosstalk between closely packed Hall sensors, which makes calibration important. Planned firmware includes a sensor calibration loop, outlier rejection, the D-pad logic and the USB stack.
